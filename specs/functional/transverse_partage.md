# Contexte

Cette page décrit le mécanisme de partage d’éléments dans cette application. Toutes les features qui sont partageables suivent ce mécanisme, ceci afin d’avoir un système unifié de partage et un parcours utilisateur commun.

Cela permet également d’avoir un monitoring plus simple à suivre.

# Principe de base

De base, rien n’est partagé. Tout élément est personnel.

Le partage de base est avec celui de sa famille, celle qui est active.
